RIG-Omni

An Open-Source ESP32-S3 Firmware for Multipurpose Intelligent Robots

ESP32-S3 · Voice AI · EAF Animation · MCP Remote Control · Multi-Bot Architecture

🌟 View on GitHub 📖 Full README

✨ Features

🧠

Voice AI

Offline wake word, cloud ASR/TTS, VAD, AGC — natural voice interaction on a microcontroller.

🎭

Emotion Display

EAF animation engine on LVGL, 20+ expressions with dynamic transitions on a 240×240 round LCD.

🤖

Motion Control

Multi-servo & wheel motor control with IMU-based balance and preset actions.

📡

Connectivity

BluFi provisioning, OTA firmware updates, HMAC device activation.

🔧

MCP Tools

Extensible remote command framework — control your robot programmatically.

📷

Camera

ESP32-S3 camera integration with snapshot capabilities via MCP.

🤖 Robot Forms

🐶

RIG-Puppy

5-Servo Robot Dog
Gait control · Head tracking · Emotive actions

🛞

RIG-Hover

2-Wheel Hovercraft
Balance control · Differential drive · Debug server

🚀 Quick Start

# Clone & enter
git clone https://github.com/Xgorobot/RIG-Omni.git
cd RIG-Omni

# Source ESP-IDF
source ~/esp/esp-idf/export.sh

# Configure board type
idf.py set-target esp32s3
idf.py menuconfig  # → RIG-Omni → Board Type → Puppy / Hover

# Build & flash
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
