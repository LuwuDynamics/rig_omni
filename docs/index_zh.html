🔧 硬件

组件接口说明
GC9A01 圆形 LCDSPI240×240，通过 LVGL 播放 EAF 表情动画
IMU（QMI8658C）I2C6 轴姿态 + 平衡控制
舵机UART（XGO）Puppy: 5 舵机，Hover: 1 舵机 + 2 DC 电机
音频编解码器I2S单工/双工 麦克风 + 扬声器
摄像头（OV2640）DVP通过 MCP 工具实现快照
按键 + 触摸GPIO配网、对话切换、NVS 重置

🚀 快速开始

# 克隆仓库
git clone https://github.com/Xgorobot/RIG-Omni.git
cd RIG-Omni

# 激活 ESP-IDF
source ~/esp/esp-idf/export.sh

# 配置板型
idf.py set-target esp32s3
idf.py menuconfig  # → RIG-Omni → Board Type → Puppy / Hover

# 编译 & 烧录
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
